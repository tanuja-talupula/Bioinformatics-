## 🧪 Projects

### 1. DNA Nucleotide Counter

A simple Python program that counts the occurrences of the four DNA nucleotides:

* **A** – Adenine
* **T** – Thymine
* **G** – Guanine
* **C** – Cytosine

**Example DNA sequence:**

```text
ATGCGTACGTTAGCTAGCTAACGATCGATCGTACGATCGTAGCTAGCTAGGCTAACG
```

**Technologies:**

* Python
* Dictionaries
* Loops
* Basic string processing
* Matplotlib
